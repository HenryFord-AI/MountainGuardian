# satellite_images

本目录用于保存吉隆案例的卫星/遥感参考图。生成本 Case Pack 的运行环境无法直接访问外网，因此图片文件未在打包时自动下载。

在本地联网电脑执行上一级目录的：

`python download_satellite_images.py`

即可尝试下载 5 张参考图。

核心公开Sentinel-2场景：
- 灾前：S2A_45RUM_20260824_1_L2A，2026-08-24 05:11 UTC，10m
- 灾后：S2B_45RUM_20260827_0_L2A，2026-08-27 05:10 UTC，10m，灾后整景云量约78%

使用原则：灾前影像作为环境/河谷基线；灾后影像仅作为验证，不得作为“灾前预测”输入。
